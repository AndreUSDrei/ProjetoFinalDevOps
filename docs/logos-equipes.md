# Logos das equipes

As imagens locais em `public/logos/teams/` foram obtidas do repositório comunitário [lootmarket/esport-team-logos](https://github.com/lootmarket/esport-team-logos/tree/master/valorant). Elas são distribuídas junto com o projeto para que o seletor e a interface continuem exibindo as logos sem depender de um serviço externo.

Os nomes e logos das organizações pertencem às respectivas organizações. Este projeto é independente e não é afiliado nem endossado por elas ou pela Riot Games.
